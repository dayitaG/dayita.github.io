# Dayita Guha | Portfolio

Data analytics and international growth portfolio, hosted on GitHub Pages.

- `index.html` is the portfolio home page.
- `dublin-stress.html` is the team dashboard "Is Dublin: Ireland's Most Stressed City?" (Silver Award, NCI Data Visualisation Challenge 2026).

## Publish

1. Create a public repository named `<your-username>.github.io`.
2. Upload all three files to the root of the repository.
3. Go to Settings, then Pages, and choose the `main` branch and `/ (root)`.
4. Your site goes live at `https://<your-username>.github.io` in a few minutes.
